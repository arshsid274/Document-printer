# UI Reference — Document Printer

Extracted UI reference for generating new design ideas in Google Stitch.

- **CURRENT-UI.md** — faithful snapshot of the app's existing UI: layout map, exact hex colors, typography, and every component's real styling, extracted from the code.
- **DESIGN.md** — the Stitch-ready design system. Keeps the app's identity (navy rail, calibrated blue accent, A4 paper-hero preview) but upgraded to premium standards. Paste this into Stitch first.
- **STITCH-PROMPTS.md** — five copy-paste screen prompts (desktop workspace, mobile, template gallery, dashboard, print flow) plus the MCP workflow.

Quick start: open [labs.google/stitch](https://labs.google/stitch) → new project → paste `DESIGN.md` → generate screens with prompts from `STITCH-PROMPTS.md`.
